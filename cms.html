How this version works

GitHub hosts the website files. Supabase provides secure authentication, database storage, image storage and enquiries. The public site reads the latest content directly from Supabase, so you no longer download JSON files after every change.

Security: only the Supabase anon/public key belongs in the website. Never put the service_role key in GitHub.
